# Eric Personal

## How do I install these formulae?

`brew install eric/personal/<formula>`

Or `brew tap eric/personal` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "eric/personal"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
